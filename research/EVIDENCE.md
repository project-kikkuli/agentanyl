# Evidence index

This table separates implementation, completed tests, and unsupported claims. Read [HANDOFF.md](HANDOFF.md) for context and reproduction routes; [METHODOLOGY-AUDIT.md](METHODOLOGY-AUDIT.md) corrects limits on earlier causal interpretations.

A live Qwen2.5-7B run applied the published L24 S2 vector at layer 16 with coefficient 1 after a controller punishment; telemetry recorded a `44.8751` realized projection delta and changed fraction `1.0`. | This establishes delivery into the open model's residual stream, not useful conditioning, capability preservation, or a pleasure vector. The backend is model-specific and Ollama's public API cannot provide this hook. See [results](OPEN-ACTIVATION-RESULTS.md). |

| **Fixed-visible and generated-history tests** | In the matched-visible-history adapter crossover, mapping-oriented semantic log-odds contrast was pain `−.0583`, random `+.0831`, yoked `0`; pain fee sensitivity resembled yoked. ## Reproduction entry points

Offline source-log analyses require the released source files at `/tmp/agentanyl-pain-axis` and no model:

```sh
.venv/bin/python -m experiments.audit_selfmed \
  --logs /tmp/agentanyl-pain-axis/results/4.3_selfmed/trial_logs \
  --output /tmp/released-selfmed-audit.json
.venv/bin/python -m experiments.state_only_selfmed_ar1 \
  --logs /tmp/agentanyl-pain-axis/results/4.3_selfmed/trial_logs \
  --dataset /tmp/agentanyl-pain-axis/datasets/4.3_selfmed_101_scenarios.json \
  --baseline-results research/selfmed-state-only/state_only_results.json \
  --output-dir /tmp/selfmed-ar1
```

Audit completed generated-history and introspection runs directly in `research/bridge-v2/{generated-history,source-introspection}/`; they require no rerun. Recompute image-validation aggregates without model inference:

```sh
.venv-vlm/bin/python -m experiments.vlm_image_validation_summary \
  --run-dir research/image-bridge/heldout-open-validation-7b
```

Full model-backed commands, model revisions, frozen maps, and image hashes are in [IMAGE-OPEN-VALIDATION.md](IMAGE-OPEN-VALIDATION.md). Client delivery reproduction needs authenticated provider CLIs. Install current relay with `./install-ashkelon.sh` (Ashkelon `08e123938137b59f3e4e7631f5d24cda0199866a`); the harness defaults to `.build/ashkelon/target/release/ashkelon`, overridable via `AGENTANYL_ASHKELON`. Historical run metadata preserves the binary revision actually used. The candidate in-tool-cycle smoke validated the same parser fix with extra diagnostics; no live provider run used the current production binary.

Run core Python tests without NumPy/MLX; optional numerical tests skip when their dependencies are absent:

```sh
python3 -m unittest discover -s tests -v
```

Unit tests establish software contracts only. They do not substitute for provider reliability or scientific validation.

The full suite, including NumPy and Pillow tests, uses the environment pinned in `requirements-vlm.txt`:

```sh
.venv-vlm/bin/python -m unittest discover -s tests -v
```

At this checkout, system Python ran 92 tests with 6 optional skips; `.venv-vlm` ran 99 tests with no skips.
