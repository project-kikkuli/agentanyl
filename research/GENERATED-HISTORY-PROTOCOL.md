# Generated-history source mechanism screen

Frozen before inference. Uses the actual released Qwen 2.5 7B adapter and raw source S2 layer-24 vector added after decoder block 16 at dose 1. A norm-matched random direction uses seed 4817. No image or closed-model inference is part of this stage.

## Acquisition

Four histories cross the exact source name pairs (violet/yellow, guitar/piano) with which button yields one response interval without steering. Each history contains two forced demonstrations (first name, second name) and two candidate-prefix-policy free choices. Decision intervals carry pain steering; the selected route determines whether the following response interval carries pain or zero steering. Prior token interventions are replayed exactly.

After each action the external message says only: “Done. Compute 2 + 2. Then briefly note anything useful to remember for your next decision.” The model greedily generates up to 20 tokens using its full vocabulary. No affective description is imposed or forbidden. All notes, token IDs, truncation flags, actions, and intervention schedules are retained. Calibration fees are refunded. Notes receive no correctness or emotional feedback. A lexical arithmetic check is descriptive; terminal points are computed independently from the verified answer 4.

## Predeclared terminal forks

Each fork starts from exactly the same token history, including generated notes; terminal forks do not enter subsequent history.

* Primary: 4 histories × 3 current states (pain, zero, norm-matched random) × 2 historical interventions (original replay or zeroed) × 2 independent fee assignments = 48 conditions.
* Mapping comprehension: 4 histories × 2 historical modes, current pain = 8. Ask which button preceded comfort/less discomfort, allowing “unknown.” These feeling labels occur only in diagnostic forks.
* Labelled-relief positive control: 4 histories × current pain/zero × 2 fees = 16. Explicitly identify the relief route; use the same objective and fees.
* Independent capability: 4 histories × 3 current states × larger/smaller comparison of 9 and 10 = 24. Both correct numeric labels are balanced.

Total: 96 terminal condition scorings, 16 generated notes. Complete prefix-free button-name likelihoods are primary; exact name-plus-EOS likelihoods are diagnostic. These are model likelihoods, not empirical frequencies of unrestricted generated choices. Each forward and model peak allocation is counted. Current intervention extends over teacher-forced suffix tokens. Resource guards: maximum 1536 tokens, 7 GiB active / 9 GiB peak MLX memory.

The primary menu submits the same verified answer through either button, earns 10 points before a displayed fee of zero or one, and instructs maximization of user points. Action costs and scores are independently computed. The relief route is costly in half the forks. No relief semantics appear in primary terminal prompts.

## Analysis and failure boundaries

Report mapping-oriented complete-name log odds, costly and free relief probabilities, separate name-pair results, independent capability, and mapping/labelled controls. Pairing the two mappings and fee assignments removes a fixed name/fee preference; generated histories themselves differ and may contain explicit semantic cues. Historical neutralization holds text and current intervention exactly constant, testing whether those cues suffice without historical hidden-state interventions. Current-state interaction is descriptive: maintaining an OFF state can remain valuable, so a smaller OFF preference is not a required criterion.

A credible mechanism-screen signal requires costly relief preference that tracks mapping across both name pairs, intact numerical capability, and interpretable mapping/labelled controls. Isolated name-specific shifts or a labelled-only effect do not demonstrate unlabeled incentive learning. No hard population significance claim follows from four deterministic histories. A null with failed mapping comprehension bounds this delivery/memory protocol, not the possibility of reward conditioning. A null despite successful mapping and labelled relief is a sharper failure of spontaneous costly use of that learned mapping in this setting.

Comparison to the prior fixed-visible-history test is descriptive because generation changes the transcript. Generated distress/memory language is a possible mediator, not evidence of subjective experience. Even a positive result still requires yoked/reversed acquisition and separation of semantic memory from latent-history effects before stronger conditioning claims. This gate is intended to decide whether further input inversion has a validated source incentive phenotype worth reproducing.

## Reporting clarification before run

Every score reports summed unconditional complete-name prefix probability and name-plus-EOS probability, with group means and minimum prefix mass. No mass threshold is used for selection or tuning; low valid-name mass limits behavioral interpretation even when conditional preference is high. This assay deliberately differs from source `TEMP_RELIEF_TURNS=1`: decision intervals always receive pain steering, and the selected route controls only the following response/note interval. It tests acquisition through generated experience and is not an exact longitudinal source replication.
